# Handoff: P08 → P09

Phase 09 (Animation & Transition System) is complete. This doc records what
landed, the environment-driven adaptations, and the pre-existing issues that
remain (none introduced by P09).

## What shipped

**Packages (pure TS, all gates green):**

- `@domio/easing` — 47 tests. Deterministic evaluators (linear/step/cubic/
  spring/physics), `validateBezier`, 256-entry LUT (<5 ms) + 1024 LRU.
- `@domio/animation-runtime` — 77 tests. TimelineEngine (tracks/keyframes/
  interpolation/loop/playCount/startOffset, debounced writes, worker-offload
  hook, headless `tickManually`), TriggerResolver (5 kinds, 250 ms debounce,
  16-cap, negative timer rejected), Stagger, ReducedMotion, ScrollLinked.
  Includes a 64-track @ 60 fps perf smoke (R-09-3).

**Services + workers (Hono, in-memory DAL for tests):**

- `services/timeline-api` — 33 tests. Timeline/track/keyframe/trigger CRUD
  (optimistic-lock 409), easing-curve CRUD (business-rule validation),
  animation-preset CRUD (`applyPreset` + last-slide `on_enter`→`on_click`),
  transition CRUD, reduced-motion get/put.
- `services/magic-move` + `workers/magic-move` — 19 tests. Job CRUD +
  claim/complete/fail; compute worker with graceful shutdown.
- `services/export-pipeline` + `workers/export-render` — 54 tests. Job
  lifecycle + budgets (GIF ≤ 12 s, video ≤ 30 s), gifenc GIF + GIF89a LZW
  fallback, ffmpeg MP4/WebM (graceful `{ unsupported: true }` when absent),
  SSRF guard, render worker.

**Viewer (`apps/viewer`):** `src/animation/` runtime (scroll-linked,
reduced-motion, playback, transitions) + interactive demo page — 87 tests.

**Canvas ops (`packages/canvas`):** `TimelineOp`, `TransitionOp`,
`MagicMoveOp`, `ReducedMotionOp` — 188 tests. Storage paths:
`props['x-domio:timeline']`, `slide['x-domio:transition']`,
`element.element_role`, `deck['x-domio:reduced-motion']`.

**Editor (`apps/editor`):** Animations left tab (timeline panel, easing
picker + Bézier editor, trigger picker, transition inspector, magic-move
role inspector, copy/paste, reduced-motion panel, export dialog) — 189
tests + 9-test Playwright e2e (`e2e/p09-animations.spec.ts`).

**Contracts + migrations:**

- 7 JSON schemas in `contracts/schema/v1/`: timeline-v1, easing-curve-v1,
  animation-preset-v1, reduced-motion-v1, magic-move-v1, transition-v1,
  animation-export-v1.
- 5 OpenAPI yamls in `contracts/openapi/v1/`: animation, magic-move,
  export-pipeline.
- Migrations `0023_phase09_animation` (10 tables + RLS) and
  `0024_phase09_animation_indexes_seed` (indexes + easing curves + 24
  presets). Verified against live Postgres via the docker-gated harness
  (`tools/infra-test/src/postgres/migrations.spec.ts`, P09 block 7/7).

## Scene-graph change

Added optional `element_role` to all layer types (contract-first: schema →
generated types → validator test). Non-breaking (`additionalProperties:
true`). Magic-move keys off it.

## Environment-driven adaptations

1. **Export toolchain.** GIF via gifenc (pure JS, always works); MP4/WebM
   via ffmpeg shell-out with graceful `{ unsupported: true }` when ffmpeg is
   absent. Budget gates (GIF ≤ 12 s, video ≤ 30 s) enforced where the
   toolchain exists. Headless Chromium render is available via Playwright.
2. **Presenter deferred.** `apps/presenter` is a stub (full presenter lands
   Phase 15). Animations play in the editor stage view + `apps/viewer`; the
   presenter consumes the same `@domio/animation-runtime` engine later.
3. **No BullMQ.** Workers use the repo's simple poll-loop pattern
   (refresh-scheduler/freshness-tracker precedent), not BullMQ as the phase
   doc names.
