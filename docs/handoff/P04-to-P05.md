# Phase 04 → Phase 05 handoff

> **Status:** P04 closed; P05 persistence/versioning/branches landed.
> **Owners:** Realtime lead (P04) → Data platform + Editor leads (P05).
> **Goal:** document the contracts P05 consumes from realtime collaboration and the surfaces P06 can depend on.

## 1. P04 inputs consumed by P05

- Realtime ops carry stable `opId`, `deckId`, `branchId`, `authorId`, HLC and Yjs payloads.
- `crdt_logs` is the durable replay source; P05 materialization maps protocol op kinds to `crdt`, `checkpoint`, `merge`, and `restore`.
- `branch_heads` provides the live `(deck, branch)` HLC/revision boundary used by checkout and optimistic merge commits.
- Editor sync preserves unsynced local ops and exposes branch switching through the branch client.

## 2. P05 delivered surfaces

### 2.1 Schema versioning and revisions

- `packages/schema/src/versioning.ts` inspects snapshot versions, validates replay compatibility, and performs migration-on-read.
- `services/control-plane/src/deck/revisions.ts` owns optimistic revision bumps and rejects stale expected revisions.
- Old snapshots are upgraded on read without mutating the persisted source blob.

### 2.2 Branches and merge requests

The branch module in `services/control-plane/src/branch/` provides:

- branch create/list/get/archive/restore/checkout and lineage walking;
- content-aware three-way structural diff at slide, element, and path granularity;
- MR create/get/list/resolve/commit;
- `theirs`, `ours`, and manual per-path conflict resolution;
- optimistic target-head advancement and idempotent commit;
- framework-neutral REST handler functions;
- audit and metrics adapters.

Editor surfaces live in `apps/editor/src/branch/` and include branch list/create/switch/archive, a three-pane merge request view, and per-conflict resolution previews.

### 2.3 Checkpoints and history

- `services/control-plane/src/checkpoint/` implements named/auto checkpoint create/list/get/rename and non-destructive restore.
- `apps/editor/src/history/` renders checkpoints inline with local, remote, merge, branch-switch, and agent timeline entries.
- Restore creates a new forward revision; it never rewinds a branch head.

### 2.4 Persistence workers

- `workers/sync/internal/materialize/` normalizes op kinds and removes duplicate op IDs by highest HLC.
- `workers/sync/internal/snapshot/` records snapshot size/duration and failure metrics.
- `workers/render/cmd/diff-renderer/` consumes `render.diff.thumbnail` and publishes deterministic thumbnail metadata on `render.diff.thumbnail.done`.
- `internal/ulid/` provides thread-safe process-local ULIDs for worker event IDs.

## 3. Contracts P06 may depend on

P06 components/templates may safely build on:

1. `DeckDocument` reads always pass through schema-version inspection and migration.
2. Every component edit is branch-local until merged.
3. Structural diffs use stable slide and element IDs plus JSON-style property paths.
4. Component-instance override maps can be diffed and manually resolved like any other element property.
5. Checkpoints pin immutable revisions and are valid anchors for branch creation and template publication.
6. Branch checkout returns a resume HLC so realtime replay resumes from the correct causal boundary.
7. Timeline entries expose timestamp, author, kind, preview, and revision and can represent agent edits from later phases.

## 4. Observability and audit contract

Metrics:

- `branch_create_total`
- `branch_diff_duration_ms`
- `branch_merge_duration_ms`
- `checkpoint_restore_total`
- `snapshot_size_bytes`
- `snapshot_duration_ms`

Alerts are configured for branch diff p95 above 2 seconds and snapshot duration p95 above 5 seconds. Branch create/archive and merge commit handlers emit audit records containing actor, deck, branch/MR IDs, and resulting revision. ACL guards can be injected before MR reads and branch/merge writes.

## 6. Deferred by design

- The diff-renderer currently emits deterministic placeholder thumbnail metadata; the headless browser/GPU renderer lands in the rich rendering phase without changing the NATS contract.
- Production metrics/audit adapters bind the in-memory interfaces to Prometheus/OTel and the `audit.events` bus subject at deployment composition time.
- Component/template semantics, registry, overrides UI, and template publishing belong to P06; P05 only guarantees their persistence, branch, diff, and checkpoint substrate.
