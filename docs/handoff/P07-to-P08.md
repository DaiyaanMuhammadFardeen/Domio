# Phase 07 → Phase 08 handoff

> **Status:** P07 theming/brand/design-tokens closed; P08 live data & interactive charts landed.
> **Owners:** P07 Stream A (theme-service + brand-service + workers) → P08 data-plane workstreams (M1 connectors, M2 query gateway, M3 formula engine, M4 chart pipeline, M5 cross-cutting).
> **Goal:** document the P08 data-plane surfaces, how they integrate with the P07 ecosystem, and what P09–P22 can build on.

## 1. P07 inputs consumed by P08

- **Theme tokens (`@domio/tokens` / `@domio/theme`)** — chart renderers and threshold style overrides resolve colors through the token system; the P08 chart engine accepts theme-token palettes in render options.
- **A11y audit shape (`token.audit_a11y`)** — chart palette identifiability under CVD (P08 §10.3) consumes the same severity/location/fixProposal shape (per P06→P07 §3.4).
- **Canvas ops + HistoryEngine (`packages/canvas`)** — P08 bindings and thresholds are committed as `DataBindingOp` / `ThresholdOp` through the same HistoryEngine as P06's `PropEditOp` / `VariantChangeOp`, so undo/redo and future Yjs collab stay consistent. **Editor HistoryEngine is constructed once (useState initializer).**
- **Component catalog (`@domio/components`)** — P08 live charts are `domio.live-*` component defs (14 chart types) in the same catalog; `expandComponent` handles their scene-graph rendering.
- **PII detection (`@domio/redact-pii`)** — connector-framework's column PII shape detection reuses its email/phone/SSN patterns.

## 2. P08 delivered surfaces

### 2.1 Formula engine (`packages/formula-engine`)

- Parser (lexer → AST) for spreadsheet-style formulas; ~50 built-in functions across aggregation/logical/text/date/lookup/math.
- Typed error codes: `#DIV/0!`, `#REF!`, `#CYCLE!`, `#NAME?`, `#VALUE!`, `#N/A`, `#NUM!`, `#NULL!`.
- `FormulaDependencyGraph` with cycle detection reporting the reachable path; `incrementalRecompute` re-evaluates only dirty dependents (slider drags).
- Constant folding + common-subexpression elimination (`optimize.ts`).
- Sandboxed evaluator (`evaluateSafe`): pure tree-walker, no `eval`/`Function`/`globalThis`/I/O; host-access rejection (uppercase identifier check — parser normalizes to uppercase) + step/recursion/runtime caps.
- **288 tests.**

### 2.2 Chart engine (`packages/chart`)

- 14 chart types: bar, line, area, pie, scatter, funnel, sankey, treemap, heatmap, waterfall, gauge, radar, candlestick, bullet.
- SVG-first renderer; tri-stack renderer interface (`svg`/`canvas2d`/`webgl`) with hybrid escalation thresholds (1k / 10k points).
- Per-type binding schemas, `validateBinding`, `requiredBindings`, `bindingCompatible`.
- Interaction layer: `hitTest`, `drill`, `toggleSeries`, `brushZoom`.
- Data tables: `sortDataset`, `paginate` (cursor beyond 10k), locale-aware `format`, `applyConditionalFormat` (thresholds), `sparkline`.
- **84 tests.**

### 2.3 Mock data (`packages/mock-data`)

- Seeded deterministic generator: uniform/normal/lognormal/poisson/categorical/date/currency distributions + correlated demos.
- **26 tests.** Editor demo datasets (Revenue Metrics, User Analytics, Sales Pipeline) live in `apps/editor/src/lib/live-data-store.ts`.

### 2.4 Connector framework (`services/connector-framework`)

- Versioned adapter registry with pin/caret/deprecation policy; 10 adapters (sheets, excel, airtable, notion, postgres, mysql, bigquery, snowflake, rest, graphql) on an injectable `Transport`.
- Canonical normalization (columns/rows, semantic roles dimension/measure/date/currency/percent), PII shape detection, exponential backoff + jitter + circuit breaker.
- OAuth handlers (Google/Microsoft/Airtable/Notion) with state + scope; credential validation (postgres/mysql/bigquery/snowflake/rest/graphql); `create-readonly-role` SQL for Postgres 14+ / MySQL 8.
- Real SaaS OAuth is **config-only in staging**: adapters run on recorded-provider fixtures in CI; the Postgres adapter additionally has a docker-gated real integration test.
- **126 tests.** OpenAPI: `contracts/openapi/v1/connector-framework.yaml`.

### 2.5 Query gateway + refresh scheduler

- `services/query-gateway`: token-bucket rate limiter, 3-tier cache with single-flight, ACL deny-by-default, HMAC webhook ingestion + idempotent dedup, single-use viewer tokens (TTL + scope), append-only tamper-evident audit. **33 tests.**
- `workers/refresh-scheduler`: `on_interval` ticking with drift ≤1s, `eager` triggers, writes `dataset_snapshot` + `freshness_record`. **14 tests.**
- OpenAPI: `query-gateway.yaml`.

### 2.6 Scenario manager + localization

- `services/scenario-manager`: scenario DAG (parent chains, cycle detection with reachable path, depth cap 8), overlay merge (parent-first, child-wins), diff. **28 tests.** OpenAPI: `scenario.yaml`.
- `services/localization`: Intl formatting + collation (en/de/bn), fixed-point Decimal, FX rate ingest + as-of convert. **32 tests.** OpenAPI: `localization.yaml`.

### 2.7 Embed proxy + freshness tracker

- `services/embed-proxy`: SSRF guard (loopback/RFC1918/link-local/metadata/DNS re-check), single-use TTL tokens, authenticated forwarding. **61 tests.** OpenAPI: `embed-proxy.yaml`.
- `workers/freshness-tracker`: append-only records (ok/stale/error/never), staleness math with grace period. **25 tests.** OpenAPI: `freshness-tracker.yaml`.

### 2.8 Contracts + data plane

- JSON Schemas: `chart-binding-v1`, `scenario-v1`, `annotation-v1`, `query-v1`, `threshold-rule-v1`, `mock-data-v1` (draft 2020-12, `contracts/schema/v1/`).
- Migrations: `0021_phase08_data_plane` (12 tables: data_connection, data_source, query, dataset_snapshot, scenario, formula_field, chart_widget, chart_binding, annotation, threshold_rule, embed_config, freshness_record — RLS via `current_setting('app.tenant_id')` following the 0003 pattern) and `0022_phase08_live_data_indexes_seed` (indexes + 4 freshness policies + 24 threshold-rule templates). **Verified against live Postgres 16** — docker-gated harness `tools/infra-test/src/postgres/migrations.spec.ts` P08 block: apply, columns, indexes, RLS policies on all 12 tables, seed counts, full insert chain, and 0022→0021 rollback (18/18 harness tests green).

### 2.9 Editor live-data UI (`apps/editor`)

- Data Sources tab (`p08-data-tab`): demo datasets + add/refresh/remove mock datasets.
- Live-chart inserts: 14 chart types via `domio.live-*` catalog defs (search "Live Bar" etc.).
- Bind-to-data inspector (`p08-bind-inspector`): source select (`p08-bind-source`, **match by value** — option labels include row counts), field mapping per required role, `validateBinding` status.
- Threshold rules panel (`p08-threshold-panel`, add rule `p08-threshold-add`), scenario switcher dropdown (`p08-scenario-btn`), stage-view toggle, freshness status.
- Data flows commit through `DataBindingOp` / `ThresholdOp` / `FilterOp` (props `x-domio:binding` / `x-domio:thresholds` / `x-domio:filters`).
- Cross-chart filters (CrossLink): Filters left tab (`p08-filters-tab`, panel `filters-panel`), global filters persisted via `FilterOp`; charts opt in via binding `listenToFilters` and re-render filtered.
- **161 tests (27 files)**; e2e smoke `apps/editor/e2e/p08-live-charts.spec.ts` (insert → bind → threshold → scenario) + `apps/editor/e2e/p08-cross-filter.spec.ts`. Run: `pnpm --filter @domio/editor exec playwright test` (auto-boots dev on 3100).

## 3. Contracts P09–P22 may depend on

1. Bindings live on the layer at `props['x-domio:binding']` (`{ queryId, fieldMap, listenToFilters }`); thresholds at `props['x-domio:thresholds']`. New UI must commit via `DataBindingOp` / `ThresholdOp`, never direct mutation.
2. Connector adapters are transport-injected — real SaaS wiring is a config change in staging, not a code change.
3. Formula sandbox is pure-TS with caps; V8-isolate execution (doc M3.1) remains aspirational — the tree-walking evaluator satisfies the security tests.
4. Chart renderer is SVG-first; Canvas2D/WebGL stacks are interface stubs selectable by hybrid thresholds.
5. Freshness statuses (`ok/stale/error/never`) and scenario overlays are append-only/snapshot-oriented by design for replay and audit.
6. `pnpm gen` generates contract types to `packages/schema/src/gen/` and `packages/api-client/src/gen/` — generated output is **not committed**; typecheck requires a fresh gen first (pre-existing editor typecheck errors in P04 sync files / draft `sdk-ts` are the known un-generated state, not P08 regressions).
