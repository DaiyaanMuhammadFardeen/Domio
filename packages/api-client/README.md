# @domio/api-client

> Generated client library. Generated code lives in `src/gen/` after
> `pnpm gen`. Consumers import from `@domio/api-client` and the
> generator produces the bindings.

## Regeneration

```bash
pnpm gen
```

CI runs `pnpm gen --check` and fails the build if the generated code
is out of sync with the contracts.
