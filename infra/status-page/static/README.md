# infra/status-page/static

Placeholder for the static SPA that renders `../components.yaml` in the
browser. **Not built in P22-beta** — for now the bucket serves a
hand-written `index.html` that lists components inline, generated by
the deploy pipeline from `components.yaml`.

When we build it (post-GA), it'll be a React + Vite SPA that polls
`/components.json` and renders the live state.

Today, the deploy pipeline runs:

```sh
node -e "
  const yaml = require('js-yaml');
  const fs = require('fs');
  const { components } = yaml.load(fs.readFileSync('../components.yaml', 'utf8'));
  const html = '<!doctype html><title>Domio Status</title>' +
    components.map(c => \`<section><h2>\${c.name}</h2><p>\${c.tier}</p></section>\`).join('');
  fs.writeFileSync('index.html', '<!doctype html>' + html);
"
```

That `index.html` is what CloudFront serves. Component state is
embedded at deploy time. Until the synthetics → Lambda bridge lands,
state only changes on a deploy.
